{% if titulo == "Privacidade" %}

Política de privacidade

A privacidade dos usuários é importante para o MetaEstudo. Esta página apresenta informações gerais sobre o cuidado com os dados utilizados durante o acesso à plataforma.

Informações dos usuários

Os dados informados no cadastro são utilizados conforme as funcionalidades implementadas na plataforma, como o acesso à conta e a utilização dos recursos disponíveis.

Proteção das informações

Os usuários devem proteger suas credenciais de acesso e evitar compartilhar suas senhas com outras pessoas.

Dúvidas sobre privacidade

Em caso de dúvidas sobre o tratamento de dados, entre em contato com a equipe responsável pelo projeto.

{% elif titulo == "Termos" %}

Termos de uso

O MetaEstudo é uma plataforma voltada à organização da rotina de estudos, permitindo que os usuários acompanhem suas metas e sessões de estudo.

Uso da plataforma

O usuário deve fornecer informações corretas no cadastro, manter suas credenciais em segurança e utilizar o sistema de maneira responsável.

Responsabilidades

Cada usuário é responsável pelas informações que registra e pela utilização de sua própria conta.

Atualizações

As funcionalidades e orientações da plataforma podem ser atualizadas conforme a evolução do projeto.

{% elif titulo == "Ajuda" %}

Como utilizar o MetaEstudo

Esta seção reúne orientações básicas para ajudar você a utilizar as funcionalidades disponíveis na plataforma.

1. Acessar sua conta

Faça login com suas credenciais cadastradas. Caso ainda não tenha uma conta, utilize a opção de cadastro.

2. Organizar suas matérias

Acesse a área de matérias para visualizar e organizar as disciplinas disponíveis no sistema.

3. Gerenciar metas

Utilize a área de metas para registrar e acompanhar seus objetivos de estudo, conforme as opções disponíveis.

4. Registrar sessões de estudo

Acesse a área de sessões para organizar seus períodos de estudo, conforme os recursos disponíveis.

5. Alterar sua senha

Na área da conta, utilize a opção de alteração de senha para atualizar suas credenciais de acesso.

{% elif titulo == "Contato" %}

Entre em contato

Tem dúvidas, encontrou algum problema ou deseja enviar uma sugestão sobre o MetaEstudo? Entre em contato com a equipe responsável pelo projeto.

Suporte e sugestões

Utilize o canal de comunicação definido pela equipe do projeto para relatar dificuldades, sugerir melhorias ou esclarecer dúvidas sobre a plataforma.

Antes de entrar em contato

Descreva sua dúvida ou o problema encontrado com o máximo de clareza possível. Não compartilhe sua senha ou outras informações confidenciais.
